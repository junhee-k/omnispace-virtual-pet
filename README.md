## About The Project

This repo provides official set of templates to maintain HCS lab repositories.

If you're creating a new repository, use this as a [Template](https://docs.github.com/en/repositories/creating-and-managing-repositories).

Otherwise, copy files in this directory to corresponding locations in your repo to start!

Follow [Link](https://docs.github.com/en/communities/using-templates-to-encourage-useful-issues-and-pull-requests/configuring-issue-templates-for-your-repository) to configure multiple issue / pull request templates depending on the type
